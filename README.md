# Kickboxing PWA (Ready)

این پروژه یک PWA ساده و آماده است شامل:
- index.html
- offline.html
- manifest.json
- service-worker.js
- icon-192.png, icon-512.png

## نحوه استفاده
1. فایل‌ها را داخل ریشهٔ یک repository در GitHub قرار بده (index.html در ریشه).
2. در Settings → Pages، منبع را روی `main` و مسیر روی `/ (root)` انتخاب کن.
3. بعد از چند دقیقه سایت منتشر می‌شود.

در صورت نیاز، من می‌توانم نسخهٔ پیشرفته‌تری با HTML/CSS سفارشی، صفحات اضافی و caching پیشرفته بسازم.
